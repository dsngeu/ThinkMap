Know your project: what's decided, what's open, what's built. A zero-dependency tool
that turns `docs/plan/*.md` into a live mind map. This repo plans itself here.

## Goals
- Any project gets a planning map with one command (`npx github:dsngeu/ThinkMap init`)
- AI coding assistants write the plan files while people talk; the map updates live
- Ship as a Claude Code plugin that companies install from an internal marketplace
